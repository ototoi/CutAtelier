# Cut Atelier 実装計画

更新日: 2026-09-13

## 実装方針

画面ごとにDB操作を散らさず、制作上の不変条件を `ProjectWorkspace` モジュールへ集約する。SvelteKitのフォーム処理と将来のエージェント向けHTTPは同じインターフェースを使う。SQLiteはローカル代替可能な依存として実DBでテストし、現時点では仮のリポジトリ抽象を増やさない。

- [x] SvelteKit、TypeScript、adapter-node、SQLiteの基盤
- [x] プロジェクトとカットの永続化
- [x] カットの追加、編集、並べ替えと楽曲フレーム上の再配置

## 完了条件

段階1は、サーバー再起動を挟んでも、プロジェクト作成からカット、素材、指摘、依頼、採用までをブラウザで一巡できることを完了条件とする。生成処理は暗黙に開始しない。段階2以降は個別の受け入れシナリオを追加してから着手する。
