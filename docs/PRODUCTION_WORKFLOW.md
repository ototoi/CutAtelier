# 生成AIによるMV制作の効率化方針

作成日: 2026-09-13

## 目的と位置づけ

プロレベルの完成度を目指し、動画生成後の演出修正と再生成を減らす。速度だけでなく、人物の同一性、空間、音楽との同期、編集の流れ、修正のしやすさを制作工程全体で管理する。

本書は「黎明シグナル」の試作から得た経験を次の企画へ引き継ぐための制作方針案である。同作品の制作は中断中であり、本書の作成は再開を意味しない。新規生成や自動化の実装は別途着手する。

生成方式の比較結果は特定素材・設定での経験であり、一般的な品質保証ではない。効果量は後述の20〜30秒パイロットで測る。

## 推奨する制作工程

### 1. 全曲の仮編集を先に作る

提供された最終ミックスとボーカルStemを同じ時間軸へ置き、静止画やラフ映像による全曲の仮編集を作る。歌詞の区切りは参考にしつつ、カット境界は音楽の展開、視覚的なリズム、感情の変化で決める。

先に曲全体の盛り上がり、歌唱と物語の配分、重要な見せ場を確認する。構成が固まる前に全カットの完成キーフレームを大量生成しない。

口元を明瞭に見せる歌唱カットには同期確認を割り当てる。後ろ姿、手元、背景なども使い、厳密なリップシンクが必要な箇所を演出上の要所へ集中させる。

### 2. 場所ごとの共通セットを作る

ステージ、屋上など、繰り返し使う場所には共通のBlenderセットを用意する。人物、レール、マイク、背景の主要物、光源、移動可能な床面を同じ座標系で管理する。

カットごとに記録するのは、セットの版、人物と小道具の位置、カメラ開始・終了位置、注視点、画角、許可する動作である。人物が静止するカットでは、ガイドの人物も静止させる。「ガイドの歩行を無視せよ」というテキスト指示だけに頼らない。

キーフレームも同じセットの構図を基準にする。Blender動画と画像で異なる背景配置やカメラ運動を要求すると、参照同士が矛盾する。ガイドは完成画の外観ではなく空間と運動の資料として扱い、生成結果で一致を確かめる。

### 3. 隣接カットをまとめて設計する

動画生成前に「前カット終端／今回の開始／今回の終了／次カット開始」を並べる。

- 視線と進行方向が意図なく反転していないか
- 人物、衣装、マイクなどの小道具が連続しているか
- 人物サイズの変化が、カメラ移動または意図したハードカットとして説明できるか
- 背景の主要物、光源、床とレールの位置が矛盾しないか
- 始終端の間に、指定尺で実行できる動作だけを要求しているか

始終端の完全一致を自動的に使い回さない。カメラが固定でも、演技や光の変化に対応する異なる終端を用意する。境界画像の共有は、同一構図で連続させたい箇所に限る。

### 4. カットの性質で生成方法を選ぶ

| カットの性質                             | 初期候補                                       | 注意点                                       |
| ---------------------------------------- | ---------------------------------------------- | -------------------------------------------- |
| 口元が見える歌唱、始終端を強く決めたい   | FL2VA＋端点＋対応するボーカル                  | 人間が同期不良と判断したらRef2VA等を比較する |
| 同じ場所で小さな動作、空間の連続性が重要 | 単一Ref2V＋整合した空間ガイド＋端点            | 長尺の品質と計算時間を実測する               |
| 走り、急回転、大きな身振り               | 動作を減らすか、演出上成立する短いカットへ分割 | 一律2秒という上限にはしない                  |
| ほぼ無声で始終端が明確                   | FL2V                                           | 不要な歌唱口形を避ける                       |
| 波形、文字、光の軌跡など調整が多い要素   | 別レイヤーで合成                               | カメラ追従、遮蔽、照明との整合を準備する     |

一つの生成に、回転、移動、接触、背景変化を同時に詰め込まない。長さを変える前に「このカットで必要な出来事は何か」を整理する。生成の都合で切る場合も、編集上の境界として成立させる。

### 5. 生成と合成の役割を分ける

人物の演技、表情、髪の動きなどを生成の中心に置く。波形、信号軌跡、タイトル、ライトの明滅など、後から修正しやすい要素は合成を検討する。

動くカメラでは、合成要素の追従や人物による遮蔽が必要になる。すべてを別レイヤーにするのではなく、修正頻度が高く、分離の利益が大きい要素から導入する。ペンライトも、独立した揺れと明滅を制御できる構成を検討する。

### 6. 技術検査と採用確認を分ける

| 段階               | 主な確認                                         | 次へ進める条件                   |
| ------------------ | ------------------------------------------------ | -------------------------------- |
| 全曲仮編集         | 音楽、尺、見せ場、歌唱と物語の配分               | 人間が構成を確認                 |
| 隣接キーフレーム   | 方向、構図、小道具、空間、実行可能な動作         | 重要な接続の矛盾を解消           |
| 生成候補           | 読み込み、フレーム数、音声区間、黒フレーム、設定 | 技術検査に合格                   |
| 音付きブロック確認 | 原速での演技、髪、顔、同期、前後の繋がり         | 人間が採用または具体的修正を判断 |
| 仕上げ             | カラー、高解像度化、必要箇所の修復、全曲同期     | 最終視聴で確認                   |

接触シートは異常箇所の発見に使う。「歩行なし」「物体固定」「交差なし」は静止画だけで断定しない。エージェントの推奨とユーザーの採用を別々に記録し、生成成功だけで採用扱いにしない。

確認依頼は一枚・一本ごとに細切れにせず、サビなど意味のあるブロックにまとめる。問題箇所の時刻と確認してほしい点を短く添える。

### 7. 採用後に仕上げる

編集と採用テイクが固まってから、カラー調整と1080p程度への高解像度化を行う。顔修復は同一性を変える可能性があるため別途比較し、必要箇所に限定する。後処理リップシンクも、顔の解像感を確認してから使用する。

音楽は元のマスターを全曲タイムラインに一度配置する。生成音声を完成音源として使わない。カットごとのAACを繰り返し連結する運用を避け、映像のフレーム時刻と音声のサンプル時刻を管理する。秒数から各カットを個別に丸めた誤差が全曲で累積しないよう、全曲のフレーム境界から各カット尺を導く。

## 修正範囲と素材の管理

素材はプロジェクト、親カット、必要な分割カットの順に整理し、各カットに `keyframes/`、`inputs/`、`workflows/`、`intermediate/`、`outputs/` を持たせる。共通セットと人物資料はプロジェクト内で共有する。

各テイクには入力素材の版、プロンプト、モデル・LoRA・VAE・Attention設定、seed、生成時間、VRAM情報、元曲上の区間、採否と理由を記録する。採用元は明示的なファイル名と可能ならハッシュで固定し、更新時刻が最新という理由だけで選ばない。

修正時は原因に応じて戻る場所を決める。

- 光や色だけの問題: 合成・カラー工程で修正
- 人物の演技の問題: 該当テイクを再生成
- 背景や方向の問題: セット・ガイド・端点を修正してから再生成
- 尺や意味が繋がらない問題: 仮編集へ戻る

修正カットと隣接カットを再確認し、影響がない採用テイクを保持する。

## 次の企画での20〜30秒パイロット

最初は一つの場所に絞り、歌唱接写、静かなカメラ移動、短い大きな動作、合成要素を含む区間を選ぶ。

1. 音源上の区間を確定し、全区間の仮編集を作る。
2. 共通セットと主要小道具を準備する。
3. 隣接キーフレームを並べ、方向・空間を確認する。
4. カットの性質に合う方法で生成し、技術検査を行う。
5. 音付きで編集し、人間が採否を確認する。
6. カメラ、演技、エフェクトのいずれかに修正を一件入れ、必要な範囲だけで直せるか確かめる。
7. 採用区間を1080p程度へ仕上げ、品質と作業量を評価する。

記録する指標は、採用カット当たりの生成回数、採用映像1秒当たりの生成時間、人の確認時間、接続ミスの件数、修正一件当たりの再作業時間である。単純な秒単価だけでなく、動作の難易度も併記する。

目標値は初回パイロットで基準を測ってから決める。全曲展開の条件は、見せ場の品質に加え、修正範囲と制作負荷を予測できることである。

## 自動化の導入順

以下は今後の実装候補であり、本書作成時点で完成済みの仕組みではない。

1. 採用テイクと音源区間を明示する一覧、および再現可能なプレビュー生成
2. 隣接4枚の確認シートと、入力・尺・音声区間の検査
3. 原速のブロック確認動画と修正箇所の記録
4. 共通Blenderセットからガイド・構図資料を出すテンプレート
5. 波形や光軌跡など、修正頻度の高い合成要素のテンプレート
